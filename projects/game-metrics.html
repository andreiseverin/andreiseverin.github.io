Game Metrics Dashboard

A real-time game server querying and community analytics dashboard featuring dynamic Steam server integrations, automated analytics querying, and a custom drag-and-drop HTML5 canvas banner designer.

Next.js 15 React 19 MySQL GameDig dnd-kit Recharts Tailwind CSS Shadcn/ui
Key Features
  • 🔌
    Real-Time Steam Query Integration

    Continuously queries Counter-Strike and Half-Life engines using the HLQuery/GameDig protocols to extract player names, connection times, maps, and connection pings.

  • 🎨
    Drag-and-Drop Server Banner Creator

    Fully interactive, 1,100-line front-end canvas (powered by @dnd-kit/core) allowing server owners to style, drag, snap-to-grid, and design dynamic live banners containing player lists, flags, and Recharts history graphs.

  • 📈
    Hourly & Daily Telemetry Analytics

    A background querying daemon (backend-worker) polls status every 5 minutes, graphing server popularity over 24-hour windows and storing historical monthly telemetry scores.

  • 🛡️
    Granular Community Management

    Features a hierarchical permission manager where server owners can create custom roles with priority badges, delegate moderation actions (e.g. manage_news, kick_members), and view security audit logs.

  • 🗺️
    Automatic Geolocation Tagging

    Automatically looks up server IP locations on initial sync using IP APIs to display country flags alongside server listings and generated banners.

Summary

Designed and built Game Metrics, a full-stack multiplayer game server directory and community management platform. The application features a custom background worker that periodically polls Steam servers (using HLQuery/GameDig), logs live player counts and map rotations, and tracks long-term player metrics. It incorporates a drag-and-drop canvas designer allowing server owners to layout custom widgets, live player telemetry graphs (built with Recharts), and custom logos to generate live image banners. The platform is backed by a secure role-based permission system supporting customizable staff roles, granular access privileges, and IP-resolved server location tags.
