Teylo Aim Training Mod

A comprehensive aim training mod and developer platform built for Half-Life and Adrenaline Gamer, introducing bots, custom UI menus, telemetry wallhacks, and multiple interactive training modules.

Key Features
  • 🤖
    Intelligent Bot Training Engine

    Includes a classic bot training system and spawn training module utilizing customized MTBot algorithms to simulate realistic movement, player positioning, and combat encounters.

  • 📊
    Interactive Telemetry & Mechanics

    Implements real-time telemetry systems, tracking damage metrics, blue fade screens on kills, wallhack overlays, and weaponbox controls to help players analyze and polish their recoil and aim routines.

  • 🛠️
    Custom Training Map Rotations

    Comes packaged with custom maps specifically designed for aim training (`test_ro`, `test_ro2`, `teylo_training_facility`, `fire_training_facility`, `fire_reflex_training`, `fire_horizontal`, `aimtrainingcenter`, and `ptk_aimtracking2`).

  • 🏆
    Challenge Mode & Highscores

    Features a localized Challenge Mode that records player run times and accuracies, saving records to a custom Top 15 leaderboard in the system configs.

  • ⚙️
    Metamod / AMX Mod X Architecture

    Designed as a Metamod and AMX Mod X server plugin, supporting Windows and Linux dedicated servers with custom configurations, active game procedures, and a dynamic menu toggle.

Summary

Designed and developed Teylo Aim Training Mod, a custom gameplay modification and server-side plugin built with C/C++, AMX Mod X, and the Half-Life SDK. The platform implements classic and spawn training modules with intelligent bots, wallhack overlays, real-time damage telemetry, and weaponbox systems. It incorporates a customizable interactive menu, server-side configuration profiles, and a local highscore database for a Top 15 challenge mode. The plugin integrates with custom-designed training maps and runs on both Windows and Linux dedicated server environments using Metamod architectures.
