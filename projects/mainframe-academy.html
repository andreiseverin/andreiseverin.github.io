Personal Project

Mainframe Academy

A full-stack browser-based training platform that teaches COBOL, JCL, CICS, and DB2 through interactive terminal emulators, a live code editor, and 70+ structured lessons.

Next.js 16 React 19 Monaco Editor NextAuth COBOL JCL CICS DB2
Key Features
  • 🖥️
    ISPF/TSO Terminal Emulator

    Built a faithful emulator (~5,200 lines) replicating 20+ IBM panels including Edit, View, Browse, Dataset List, Library Utility, Move/Copy, and SDSF — with line commands, FIND/CHANGE, and scrolling.

  • ⚙️
    COBOL Execution Engine

    Parses WORKING-STORAGE variables (including COMP-3, BINARY, REDEFINES, OCCURS), simulates DISPLAY, MOVE, STRING, INSPECT, ACCEPT, and SEARCH statements, and formats output via PIC-clause editing.

  • 📋
    JCL Parser

    Supports JOB/EXEC/DD statements, inline data (DD *), COND parameters, and multi-step execution plans.

  • ✅
    Interactive Exercise System

    Server-side code validation, progress tracking, compilation status indicators, and a lesson-completion workflow across 70+ structured lessons in 4 curriculum tracks.

  • 📺
    CICS Terminal Emulator

    3270-style green-on-black display supporting CESN sign-on and CEMT system inquiry screens.

  • 📝
    Multi-Panel Dashboard

    Resizable/detachable panes, Monaco code editor with custom COBOL/JCL syntax highlighting (Monarch grammars), and a JES Spool Viewer for job output inspection.

  • 🔒
    Authentication & Workspaces

    NextAuth + bcrypt authentication, per-user virtual workspaces with dataset management, copybook resolution, and i18n support (EN/FR/RO).

Cover Letter / LinkedIn Summary

Independently designed and built Mainframe Academy, a full-stack web application (Next.js 16 / React 19) that teaches mainframe skills through hands-on practice in the browser. The platform features a 5,200-line ISPF/TSO terminal emulator faithfully replicating IBM panel navigation, a COBOL execution engine with PIC-clause formatting and COMP-3/BINARY support, a JCL parser, a CICS 3270 terminal, and a Monaco-based code editor with custom syntax highlighting. It delivers 70+ structured lessons across COBOL, JCL, DB2, and CICS tracks with server-side code validation, progress tracking, and multi-language support.
