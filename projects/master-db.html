MasterDB: Live Server Directory

A custom game server query directory and caching system built to support real-time GoldSource/Source engine polling, automated IP geolocation, and a pattern-based player analysis algorithm to detect and blacklist cloned redirect servers.

PHP 8.2 WordPress API MySQL xPaw/SourceQuery jQuery DataTables cURL / Geolocation
Visit Live Site
Key Features
  • 🔌
    Real-Time GoldSource & Source Querying

    Integrates the xPaw\SourceQuery library to poll Counter-Strike and Half-Life server engines via UDP query protocol, extracting active hostnames, map names, player counts, max slots, and connection latency.

  • 🛡️
    Automated Redirect & Clone Server Detection

    Designed and built a custom player-telemetry matching algorithm that compares player name distributions and score patterns across all servers. If duplicates are found, the clone servers are flagged in the database (REDIRECT: [target_ip]) to prevent fake-player listing fraud.

  • ⚙️
    Cron-Driven Cache & Synchronizer Daemon

    Operates a background database sync worker that maps online servers, logs offline state with chronological first_offline timestamps, and automatically deletes servers inactive for more than 5 days.

  • 🗺️
    Automatic IP Geolocation Lookup

    Connects to external IP location APIs on initial server registration to resolve country codes, dynamically displaying national flag icons and enabling geographic routing.

  • 📥
    Secure Submission & Anti-Spam Gatekeeper

    Implements user-facing server registration portals with custom regex validators, banned list check routines, and a rolling 24-hour database lock to limit server registration spam per user.

  • 📊
    High-Performance DataTables View

    Renders server lists in a lightning-fast, sortable, and searchable UI built on jQuery DataTables, complete with Steam connection shortcuts and copy-to-clipboard console macros.

Summary

Designed and built MasterDB, a custom game server directory and telemetry query engine integrated with WordPress and MySQL. The system periodically queries GoldSource and Source engine servers (using SourceQuery UDP protocols) to cache map rotations, player numbers, and latency scores. To protect the list from traffic-hijacking fraud, I designed and implemented a player-pattern comparison algorithm that matches player names, score telemetry, and metadata to automatically identify and isolate cloned redirect servers. The platform features automated IP-to-country geolocation mapping, scheduled database synchronization crons, and a high-performance jQuery DataTables search portal.
